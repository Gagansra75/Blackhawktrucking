## 🚀 PUSH TO GITHUB IN 3 STEPS

### Step 1️⃣: Create GitHub Repository

**Visit:** https://github.com/new

Fill in:
```
Repository name:    trucking-website
Description:        Professional e-commerce website for truck accessories
Visibility:         Public (anyone can see) or Private (only you)
Initialize with:    NOTHING - leave all unchecked!
```

Click: **"Create repository"**

### Step 2️⃣: Copy Your Repository URL

After creating, you'll see a page with commands.

**Copy the HTTPS URL** that looks like:
```
https://github.com/YOUR-USERNAME/trucking-website.git
```

### Step 3️⃣: Run These Commands

Replace `YOUR-USERNAME` with your GitHub username:

```bash
cd /Users/gagansra/Desktop/Trucking-website

git remote add origin https://github.com/YOUR-USERNAME/trucking-website.git

git branch -M main

git push -u origin main
```
