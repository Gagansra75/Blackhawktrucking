## Navigation Flow

### User Journey 1: Browse & Get Convinced
```
Home Page
  ↓ (sees featured products)
  ↓ (reads 5 testimonials)
  ↓ (clicks Testimonials link)
Testimonials Page
  ↓ (reads all 15 testimonials)
  ↓ (sees stats)
  ↓ (clicks Shop button)
Products Page
  ↓ (buys product)
```

### User Journey 2: Get Help
```
Home Page / Products Page
  ↓ (has question)
  ↓ (clicks Contact link)
Contact Page
  ↓ (reads FAQ)
  ↓ (sees contact info)
  ↓ (fills form)
Form Submitted
  ↓ (sees success message)
  ↓ (team follows up via email)
```

### User Journey 3: Build Trust
```
First-time Visitor
  ↓ (arrives at home)
  ↓ (sees testimonials section)
  ↓ (wants more proof)
  ↓ (clicks Testimonials in header)
Testimonials Page
  ↓ (reads 15 reviews)
  ↓ (sees 99% satisfaction rate)
  ↓ (convinced!)
  ↓ (clicks Shop Now)
Products Page
  ↓ (confidently buys)
```

## Color Usage

### Header/CTA Areas
- **Red Gradient**: `linear-gradient(135deg, #d32f2f 0%, #b71c1c 100%)`
- Used on: Page headers, CTA sections

### Text Colors
- **Dark Text**: `#111` (names, titles, main content)
- **Medium Text**: `#333` (body text)
- **Light Text**: `#666` (secondary info)
- **White Text**: On red backgrounds

### Accents
- **Gold Stars**: `#FFD700` (ratings)
- **Blue Button**: `#1e88e5` (live chat)
- **Green Success**: `#4CAF50` (form submission)

## Button States

### CTA Buttons (Red)
```
Normal:    [  SHOP NOW →  ]
Hover:     [  SHOP NOW →  ]  ← Darker red (#b71c1c)
Active:    [  SHOP NOW →  ]  ← Even darker
```

### Form Submit
```
Empty/Invalid:  [  SEND MESSAGE  ]  ← Gray/disabled
Valid/Ready:    [  SEND MESSAGE  ]  ← Red
Hover:          [  SEND MESSAGE  ]  ← Dark red
```

### Social Links
```
Normal:    [Facebook] [Twitter] [LinkedIn]
Hover:     [Facebook] [Twitter] [LinkedIn]  ← Red background
```
