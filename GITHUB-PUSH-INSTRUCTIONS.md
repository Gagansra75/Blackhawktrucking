## 📝 COMMAND BREAKDOWN

**What each command does:**

```bash
# Tells git where your remote GitHub repository is
git remote add origin https://github.com/YOUR-USERNAME/trucking-website.git

# Renames your branch to 'main' (GitHub's standard)
git branch -M main

# Uploads your code to GitHub
git push -u origin main
```
